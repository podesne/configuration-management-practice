# Эмулятор оболочки

Практическая работа № 1 по предмету «Конфигурационное управление».
Группа ИКБО-62-25, вариант 17. Этап 1.

Консольный прототип на Python. Программа читает команды, разбирает
аргументы и выводит результат до команды `exit`. Такой цикл называется
REPL. Имя пользователя и имя компьютера в приглашении берутся из ОС.
На компьютере, где проверялась работа, приглашение выглядит так:

```text
podesne@MacBook-Air-Marat-3.local:~$
```

## Запуск и тесты

Нужен Python 3.10 или новее. Сторонних библиотек нет, сборка не требуется.
Команды выполняются из папки проекта.

На macOS и Linux:

```sh
sh run.sh
```

На Windows:

```bat
run.bat
```

Для запуска напрямую используйте `python3 -m src.main` на macOS и Linux
или `python -m src.main` на Windows.

Запуск тестов на macOS и Linux:

```sh
python3 -m unittest discover -s tests -v
```

На Windows:

```bat
python -m unittest discover -s tests -v
```

Тесты проверяют разбор аргументов, переменные окружения, приглашение,
команды и продолжение работы после ошибок.

## Команды

| Команда | Действие |
| --- | --- |
| `ls` | Выводит своё имя и список аргументов |
| `cd` | Выводит своё имя и список аргументов |
| `exit` | Завершает программу, если аргументов нет |

На первом этапе `ls` и `cd` работают как заглушки. Они принимают любые
аргументы, не проверяют пути и не меняют текущую папку. Знак `~`
в приглашении остаётся постоянным.

Пустой ввод возвращает приглашение. Неизвестная команда, аргументы
у `exit`, незакрытая кавычка или обратная косая черта в конце строки
вызывают ошибку. После сообщения программа ждёт следующую команду.
`Ctrl+C` возвращает приглашение. Конец ввода завершает программу:
на macOS и Linux это `Ctrl+D`, на Windows это `Ctrl+Z` и Enter.

## Разбор ввода и настройки

- Пробелы и табуляция вне кавычек разделяют аргументы.
- `$HOME` и `${HOME}` подставляют значение из окружения ОС.
  Неизвестная переменная даёт пустую строку.
- Двойные кавычки сохраняют пробелы и разрешают подстановку переменных.
  Одинарные кавычки сохраняют текст буквально. Сами кавычки удаляются,
  пустые аргументы сохраняются.
- Обратная косая черта вне кавычек экранирует следующий символ.
  В двойных кавычках она экранирует доллар, кавычку и саму косую черту;
  перед остальными символами сохраняется.
- Части без пробела образуют одно слово, например `a"b c"`.

Значение переменной остаётся одним аргументом, даже если содержит пробелы.
Повторной подстановки нет. Прототип не поддерживает конвейеры,
перенаправления и запуск внешних программ.

Параметров командной строки на первом этапе нет. Скрипт `run.sh`
вызывает `python3`; через переменную окружения `PYTHON` можно выбрать
другой интерпретатор:

```sh
PYTHON=/path/to/python sh run.sh
```

## Примеры использования

В каждой паре строк сначала указан ввод, затем ответ программы.
В примере значение `HOME` равно `/Users/podesne`.

```text
ls
ls: []

ls -a "my folder"
ls: ['-a', 'my folder']

cd $HOME
cd: ['/Users/podesne']

ls '$HOME' ""
ls: ['$HOME', '']

unknown
Ошибка: Неизвестная команда: unknown

exit now
Ошибка: Команда exit не принимает аргументы
```

Команда `exit` без аргументов завершает диалог без сообщения.

## Файлы и функции

| Файл | Назначение |
| --- | --- |
| `src/main.py` | Запуск программы |
| `src/shell.py` | Приглашение, обработка команд и цикл ввода |
| `src/parser.py` | Разбор строки и подстановка переменных |
| `tests/test_parser.py` | Тесты разбора ввода |
| `tests/test_shell.py` | Тесты команд и цикла ввода |
| `run.sh`, `run.bat` | Скрипты запуска |
| `.gitignore` | Исключения для кеша, сборок и настроек редактора |

| Функция | Назначение |
| --- | --- |
| `main()` | Запускает цикл ввода |
| `run_repl()` | Читает команды до выхода и выводит ошибки |
| `build_prompt()` | Получает имя пользователя и компьютера из ОС |
| `execute_command(words, write)` | Обрабатывает команду и возвращает признак продолжения работы |
| `parse_command(line, environment)` | Разделяет строку на команду и аргументы |
| `expand_word(word, environment)` | Собирает слово из частей с учётом кавычек |
| `expand_text(text, environment, quoted)` | Подставляет переменные и обрабатывает экранирование |
| `replace(match)` внутри `expand_text` | Заменяет одну переменную или экранированный символ |

У `parse_command` окружение по умолчанию берётся из `os.environ`.
Параметр `environment` позволяет передать свой словарь для тестов.
У `execute_command` параметр `write` задаёт функцию вывода, по умолчанию
это `print`. Параметр `quoted` у `expand_text` включает правила двойных
кавычек. Описание аргументов и результатов есть в документации функций.
