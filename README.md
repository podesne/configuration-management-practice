# Эмулятор оболочки

Практическая работа № 1 по предмету «Конфигурационное управление».
Группа ИКБО-62-25, вариант 17. Этап 3.

Программа работает в терминале: читает команды, разбирает аргументы
и выводит результат до команды `exit`. Приглашение по умолчанию содержит
имя пользователя и компьютера из ОС. Его можно заменить параметром
`--prompt`.

## Этапы

| Ветка | Готовая версия |
| --- | --- |
| `main` | 1. Консоль, переменные окружения, заглушки `ls` и `cd`, выход |
| `stage-2` | 2. Параметры запуска и стартовый скрипт |
| `stage-3` | 3. Загрузка ZIP-образа VFS в память |
| `stage-4` | 4. Команды `ls`, `cd`, `head`, `tail`, `uniq` |
| `stage-5` | 5. Копирование командой `cp` |

Каждая следующая ветка продолжает предыдущий этап.

## Запуск и тесты

Нужен Python 3.10 или новее. Сторонних библиотек нет, сборка не требуется.
Команды выполняются из папки проекта.

На macOS и Linux:

```sh
sh run.sh
python3 -m unittest discover -s tests -v
```

На Windows:

```bat
run.bat
python -m unittest discover -s tests -v
```

Для запуска напрямую используйте `python3 -m src.main` на macOS и Linux
или `python -m src.main` на Windows. Скрипт `run.sh` вызывает `python3`;
переменная окружения `PYTHON` задаёт другой интерпретатор.

## Настройки

| Параметр | Назначение | По умолчанию |
| --- | --- | --- |
| `--vfs PATH` | Физический путь к ZIP-образу VFS | Не задан |
| `--prompt TEXT` | Приглашение к вводу, включая завершающий пробел | Из ОС |
| `--script PATH` | Физический путь к стартовому скрипту UTF-8 | Не задан |
| `-h`, `--help` | Справка по параметрам | Выход после справки |

Все заданные параметры печатаются при запуске. Пустое приглашение
разрешено. Пути к образу и скрипту отсчитываются от папки запуска.

Стартовый скрипт содержит по одной команде на строке. Комментарии
начинаются с `#` вне кавычек, как в Python. На экран выводятся строки
скрипта с приглашением и результаты команд. После конца скрипта
начинается интерактивный ввод; `exit` останавливает весь сеанс.

## Команды

| Команда | Действие |
| --- | --- |
| `ls`, `cd` | Заглушки: выводят имя и аргументы, каталог не меняется |
| `vfs-info` | Пути и типы записей VFS, размер файлов и данные base64 |
| `exit` | Выход без аргументов |

Пустой ввод возвращает приглашение. Ошибки команд и синтаксиса выводятся
без завершения сеанса. `Ctrl+C` возвращает приглашение. Конец ввода
завершает программу: `Ctrl+D` на macOS и Linux, `Ctrl+Z` и Enter на Windows.
Ошибки загрузки образа или скрипта дают ненулевой код завершения.

## Разбор ввода

Пробелы вне кавычек разделяют аргументы. `$HOME` и `${HOME}` берутся
из окружения реальной ОС. Неизвестная переменная даёт пустую строку.
Одинарные кавычки сохраняют текст буквально; двойные разрешают подстановку
переменных. Кавычки удаляются, пустые аргументы остаются.

Вне кавычек обратная косая черта снимает особый смысл следующего символа.
В двойных кавычках экранируются доллар, кавычка и сама косая черта.
Соседние части без пробела образуют одно слово, например `a"b c"`.
Значение переменной остаётся одним аргументом и повторно не раскрывается.
Конвейеры, перенаправления и запуск внешних программ не поддерживаются.

## Виртуальная файловая система

ZIP-образ читается в память без распаковки на диск. Содержимое каждого
файла хранится в base64. Отсутствующие записи родительских каталогов
восстанавливаются по путям файлов. Без `--vfs` создаётся пустой корень.
Символические ссылки, повторные записи и небезопасные пути в ZIP
отклоняются. Команды не обращаются к файлам реальной ОС.

## Примеры и проверочные скрипты

Архивы для проверки создаются из текстовых описаний и исключены из Git.

```sh
python3 -m scripts.make_vfs
sh run.sh --vfs examples/generated/deep.zip \
    --script examples/stage3.shell
sh scripts/check_config.sh
sh scripts/check_errors.sh
sh scripts/check_minimal.sh
sh scripts/check_several.sh
sh scripts/check_deep.sh
```

На Windows для образов используется `python -m scripts.make_vfs`,
а эмулятор запускается через `run.bat` с теми же параметрами.
Скрипты `.sh` предназначены для macOS и Linux.

Проверочные образы включают пустой корень, несколько файлов и дерево
с тремя уровнями каталогов. Стартовый скрипт текущего этапа проверяет
все доступные команды, поддерживаемые режимы и ошибки.

```text
ls
ls: []

vfs-info
/ dir
```

Этот пример соответствует минимальному образу. Команды `ls` и `cd`
остаются заглушками до четвёртого этапа.

## Функции

| Файл и функция | Назначение |
| --- | --- |
| `make_vfs.make_archive()` | Сохранить каталоги, UTF-8 текст и base64 файлы описания в ZIP. |
| `make_vfs.main()` | Создать все проверочные образы в examples/generated. |
| `config.parse_config()` | Разобрать параметры запуска; None означает аргументы процесса. |
| `config.print_config()` | Вывести все параметры перед началом диалога. |
| `main.main()` | Запустить скрипт и диалог; вернуть код ошибки запуска. |
| `parser.expand_text()` | Подставить переменные один раз и обработать обратную косую черту. |
| `parser.expand_word()` | Собрать слово из частей, сохранив правила одинарных кавычек. |
| `parser.parse_command()` | Разделить ввод на имя команды и аргументы. |
| `parser.replace()` | Заменить одну переменную или экранированный символ. |
| `shell.build_prompt()` | Получить имя пользователя и компьютера из ОС для приглашения. |
| `shell.execute_command()` | Выполнить команду и вернуть, нужно ли продолжать диалог. |
| `shell.process_line()` | Разобрать строку, вывести ошибку и вернуть признак продолжения. |
| `shell.run_repl()` | Читать команды до exit или конца ввода; после ошибки продолжать. |
| `startup.strip_comment()` | Удалить комментарий Python с # вне кавычек и экранирования. |
| `startup.run_script()` | Показать строки UTF-8 скрипта и выполнить их до exit или конца. |
| `vfs.validate_member()` | Проверить имя и отклонить ссылки или выход за корень образа. |
| `vfs.virtual_path()` | Заменить ~ корнем VFS; остальные пути оставить без изменения. |
| `vfs.__init__()` | Создать пустую файловую систему с корнем. |
| `vfs.load()` | Прочитать записи ZIP без извлечения файлов на диск. |
| `vfs.add()` | Добавить запись образа и недостающие родительские каталоги. |
| `vfs.resolve()` | Проверить все части абсолютного или относительного пути. |
| `vfs.get()` | Получить существующую запись или сообщить об ошибке пути. |
| `vfs.children()` | Вернуть отсортированные имена непосредственных детей каталога. |
| `vfs.read()` | Декодировать файл из base64; каталог читать нельзя. |
| `vfs.describe()` | Показать дерево, размеры файлов и их данные base64. |

Аргументы и результаты описаны в строках документации функций.
`parse_command` принимает необязательный словарь окружения для тестов.
Функция вывода заменяется в тестах для проверки ответов без терминала.
Тесты находятся в `tests`, скрипты ОС и генератор образов в `scripts`,
стартовые скрипты и описания образов в `examples`.
